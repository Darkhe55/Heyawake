# 数间 Heyawake

一个基于 Web 的数间（Heyawake）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5188/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 带数字的区域内黑格数等于该数字
- 黑格不能上下左右相邻
- 所有白格必须连通
- 一条直线相连的白格不能跨越两个以上区域

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 黑 → 白标记 → 空 |
| 右键点格 | 反向循环 / 清除 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **图片导入**：`npm run import-image` 可识别题图（网格 + 粗区域边界 + 数字）并写入题库
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/

  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      推理规则

```

## 识图导入

```bash
# 预览：自动识别网格、粗区域边界与每区数字，并打印线索图/区域图
npm run import-image -- 题板.png

# 指定尺寸（默认自动识别；识别不准时可手动指定）
npm run import-image -- 题板.png --width 35 --height 35

# 写入题库；--verify 启动项目 solver 校验唯一解（35×35 这类大盘面通常超时，只警告）
npm run import-image -- 题板.png --append --verify

# 某个字形簇数字识别错了：按打印出的「簇号=数字」人工覆盖
npm run import-image -- 题板.png --map 8=2

# 导出识别叠加图，核对区域划分（红色为识别出的区域边界）
npm run import-image -- 题板.png --dry --debug 叠加.png
```

识别流程：投影暗像素找网格线 → 相邻格边界中点测暗线厚度并用 2-means 区分细网格线/粗区域边界 → 四连通洪泛得到区域 → 每格墨迹连通块切成数字字形并聚类模板定值 → 按区域汇总黑格数 → 打印预览并可写入题库。

| 参数 | 说明 |
|------|------|
| `--width N` / `--height N` / `--size N` | 手动指定网格尺寸；默认自动识别 |
| `--name 名称` | 题库中显示的名称（默认 `识图 · 宽×高`） |
| `--series 系列` | 题库系列，默认 `human` |
| `--append` | 追加写入 `src/game/puzzles-data.ts` |
| `--verify` | 调 solver 校验唯一解并生成参考解；超时只警告，不写参考解 |
| `--map 簇号=数字,...` | 人工覆盖字形簇的识别结果 |
| `--thick N` | 手动指定粗线阈值（像素），区域划分异常时使用 |
| `--debug 输出.png` | 导出区域/边界叠加图，便于核对识别结果 |
| `--dry` | 只识别预览，不校验、不写入 |

已知限制：

- 题板按完整矩形处理（内置题与题图都是矩形，暂不支持异形题板）；
- 区域数超过 36 时，题面会自动用 2 字符/格编码区域号（旧格式仍可正常读取，游戏玩法不受影响）；
- 35×35 这类大盘面的 `--verify` 会超出搜索预算，只写题面、不写参考解（`npm run check` 会跳过无参考解的条目）；
- `npm run gen` 会重写 `src/game/puzzles-data.ts`，识图导入的条目也会被覆盖，需要重新导入。

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run import-image -- 题板.png   # 识图导入（预览）
npm run gen       # 重新生成题库
npm run check     # 审计题库
npm run verify    # 参考解、逻辑回放与交互验证
npm run audit     # 逐题审计逻辑解题
```

## 尺寸与棋盘支持

| 项目 | 范围 / 说明 |
|------|------|
| 棋盘形状 | 矩形，宽高各自独立，**支持非正方形**；区域按四连通划分 |
| 异形棋盘 | 不支持「盘外空格」：数间规则要求所有白格连通、每个格子都属于某个区域，没有棋盘外概念 |
| 内置题 | 6×6、7×7、8×8 |
| 自定义题板 | 5×5 – 40×40；区域号可用点击循环 1–40，或用「区域号」输入框直接填 1–999（回车 / 应用），不必点满循环 |
| 区域 / 线索上限 | 区域编码每格自适应 1 / 2 / 3 个 base36 字符：≤36 区（旧格式）、≤1296 区、≤46656 区；每区黑格数最多 46655 |
| 识图导入 | 无（本项目只有内置题库） |
| 旧数据兼容 | 旧题面（1 字符 / 2 字符区域编码）解码结果完全不变，新编码按字符串长度自动区分 |

> 本批改动：区域编码宽度从「1 或 2 字符」扩展到「1 / 2 / 3 字符」（区域数上限 1296 → 46656），
> 自定义题板区域号上限从 20 提到 40（点击循环）+ 999（直接输入），每区黑格数上限 99 → 999。
